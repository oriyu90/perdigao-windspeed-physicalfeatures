## 環境

- `uv python install 3.12`、`uv init --python 3.12`
- 依存: numpy,pandas,scipy,xarray,netcdf4,h5netcdf,scikit-learn,statsmodels,pyyaml,pydantic,pyarrow,matplotlib,seaborn,jinja2,pytest,hypothesis,ruff（weasyprintはPDF用第一候補、不可ならChromium print-to-PDF）
- lockはP0で凍結。OS/Python/wheelを保存。乱数は `Generator(PCG64)` 統一。
- master_seed `2026091501`。派生 `SHA256(master+namespace+index)` 先頭64bit。`hash()`禁止。namespace: split,rf,sham_formula,sham_statistical,rff,bootstrap,semisynth_positive,semisynth_negative。

## 時刻・期間・分割（現行踏襲）

- UTC正規化。`Z_h(T)=mean(Z in (T-h,T])`、標的 `Y_h(T)=mean(U100 in (T,T+h])`。`max source time <= issue time`。
- 開発 2016-11-29〜2017-03-10、確認 2017-03-10〜2017-06-16（14日ブロック×8、purge 3h）。2017-06-17以降未読。
- P1では確認のschema/時刻/欠測率のみ可。標的分布・相関・性能は禁止。
- `splits.parquet`: issue_time,target_start,target_end,outer_fold,role,max_input_time。

## Git凍結（内部凍結、OSFなし）

F2終了で独立repoにannotated tag `frozen-design-v1.1-YYYYMMDD`（YYYYMMDDは凍結日UTC）、`freeze_manifest.json`（全config+lock+split hash）＋`freeze_bundle.zip`（ローカル保管、外部提出なし）。F3開始条件はtag/manifest一致のみ。変更は再凍結（新tag・新bundle）とし、上書きしない。報告書では「内部凍結（OSF登録なし）」と明記し「事前登録済み」とは書かない。

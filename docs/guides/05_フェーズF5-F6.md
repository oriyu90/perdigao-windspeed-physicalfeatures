# 05 フェーズF5-F6: 頑健性・統計・レポート・検収

## F5 P4 頑健性・統計確定

開始: `P3_COMPLETE`（FAIL時は実追加解析なし・校正監査のみ）。
1. 一次推定: 日単位 `Δ_PR=RMSE(P)-RMSE(R)`、`Δ_PS=RMSE(P)-median_j RMSE(S_j)`、sham rank（Δ_PRが100 shamのΔ_SjR分布のどこか）。7日moving-block paired bootstrap 10000回固定seed。fold/seed保持、日block再標本化。5条件AND→`primary_decision.json`（後付け重み変更禁止）。
2. 等価性: SESOI=F2再計算値（定義は開発BCA RMSEの1%。現行例0.008862 m/s）。paired block bootstrap CIが[-SESOI,+SESOI]内完全包含のみ等価。非有意を等価と書かない。TOSTは補助・block単位・参考値。
3. 保存: 水平30/90/137°回転共変変換。TKE/TI/wind speed/N2/Ri不変量はrel1e-8（分母安全域）、最終予測の効果方向一致。不合格は実装不合格。
4. 破壊（凍結3系列のみ）: 高度順反転（20/100m差符号逆）/浮力符号反転（温位勾配or熱フラックス符号のみ反転）/shear対応破壊（u/v鉛直差を異時間blockで組合せ、欠測率・分布維持）。破壊がP同等以上→条件4=false。差替え禁止。
5. 二次: 10分/3時間、ElasticNet/HGB、レジーム（開発N2分位で強安定/中立/強不安定を固定、確認で再推定禁止）、QC有無、同予算探索。一次family以外はHolm補正（未補正・補正・効果・CI・N併記）。一次判定変更禁止。
6. audit自動検査: 行数/日/fold一致、群間mask完全一致、`max_input_time<=issue_time<target_start`、test混入なし、fit数とbudget一致（一次fit上限880参照）、sham欠落なし、seed重複なし、表再計算一致、CI-decision一致、F4以後差分なし。
出力: `tables/primary_results.csv,all_results.csv,calibration_results.csv,invariance_results.csv,destruction_results.csv,regime_results.csv`＋statistical/leakage audit＋decision。新run_idで上書き禁止。合格で `P4_COMPLETE`、重大不一致は `AUDIT_FAILED` でF6へ。

## F6 P5 最終レポート・再現監査

構成（20章・現行踏襲）: 表紙(version/run_id/freeze hash/生成日)→日要旨→English abstract→問い範囲→先行再現→データversion/QC/欠測→concordance→凍結記録・逸脱→時刻分割DAG対照→校正→一次→保存破壊→二次感度→反論回答→限界→再現方法→結論→可用性→文献→全試行逸脱。表紙・要旨に「内部凍結（OSF登録なし）」と明記する。
結論はdecision JSONから自動選択のみ:
- 5条件all true→「Perdigãoの指定条件で、物理変換に固有な有限標本帰納バイアスを支持した。」
- PがRに勝つが他false→「特徴工学上の利益は観測されたが、正しい物理関係への固有性は支持されなかった。」
- 等価成立→「指定条件では、物理変換追加の実用的効果は事前定義した等価幅内だった。」
- CI広→「効果の有無を判定する精度が不足した。」
- gate/audit失敗→「帰属測定系または実装監査が不合格であり、実データの帰属判定を保留した。」
禁止表現: 「物理は不要」「現実大気の因果機構を証明/反証」「他地域・他季節・他モデルへ一般化」「風力運用・防災で有用」「有意差がないので同じ」「SHAP/重要度が高いので物理」。
必須表10種・必須図7種（色覚安全、虹/3D禁止、軸単位N CI・一次/二次区別明記）。Markdownをtruthにhtml/pdf生成、日本語font埋め込み、A4余白20-25mm、render PNG検査（空白/化け/切れ）。
clean-room: 新規tmpでclone→空cache取得→`uv sync --locked`→`./run_all.sh --frozen --from-raw`。raw/processed/predictions/tables/decision/figureCSV/本文数値を比較（非一致はrtol1e-10/atol1e-12列比較）。Apple Silicon同一PCで大差が出ればAUDIT_FAILED。
検収: 08チェック全実測、`delivery/`集約＋manifest、`STATUS.md=DELIVERED`、`handoffs/PHASE_P5.md`＋`reports/提出物一覧.md`で停止。

# 00 読む順序と絶対ルール v1.1

目的: `../PLAN_v1.1.md` を変更せず、Perdigão再現・反証研究を修正版群定義で再実施する。

前提: 現行 `<PC>/研究/広大シンポジウム/現行研究 v1.0/perdigao_attribution/` は `CALIBRATION_FAILED` で確定・密封維持（`runs/exposure.jsonl`なし）。読出し専用。変更禁止。本書の相対表記 `現行研究 v1.0/...` は上記絶対パスを指す。

## 各セッションで読む順序（5点まで）

1. `../PLAN_v1.1.md`

4. `perdigao_attribution_v1.1/STATUS.md`

過去チャット全文・旧案フォルダは読まない。会話履歴を記録にしない。

## 絶対ルール

1. 実装先は `新研究 v1.1/perdigao_attribution_v1.1/` のみ。現行本体に書かない。
2. 外部データは NCAR/EOL 536.011 v1.2 のみ。DOI `10.26023/ZDMJ-D1TY-FG14`。
3. 著者コード `dvassall/Forecasting_Error_Codes@9420b715` は参照のみ。コピー・vendor化禁止。clean-room実装。
4. P群定義は `P=R+Xp`。単独Xpでのfit禁止（04章の修正コードを使う）。
5. 確認性能を見た後に特徴・期間・閾値・seed・探索範囲・結論規則を変えない。
6. FAIL/不一致は隠さず規定状態で停止。代替データへ自動遷移しない。
7. SHAP/重要度/attention/NN/追加データ禁止。
8. 数値は表から生成。手入力禁止。
9. 各フェーズ末に tests＋STATUS＋handoff＋NEXT_SESSION_PROMPT＋commit。長会話を継続しない。

## フェーズと状態

```
F0 準備・分離(F0_DONE) → F1 P0環境(P0_COMPLETE) → F2 P1凍結(P1_FROZEN)
→ F3 P2再現(P2_COMPLETE)
→ F4 P3校正(P3_COMPLETE or CALIBRATION_FAILED) → F5 P4頑健性(P4_COMPLETE or AUDIT_FAILED) → F6 P5報告(DELIVERED)
※OSF登録フェーズなし。
```

例外: `INFEASIBLE_DATA`, `CALIBRATION_FAILED`, `AUDIT_FAILED`。例外時もP5相当の報告へ進めるが帰属結論は出さない。
